# Icons

Put logo and icon images here (SVG or PNG). They appear as a round badge above a component.

In edit mode, select a component and fill in either:

- **Icon badge**: an icon for that one component, for example `icons/postgresql.svg`.
- **Icon for all "…" models**: an icon for every component of that model type, for example `icons/kubernetes.svg` for every Kubernetes cluster.

Square images with a transparent background look best. The badge adds a white circle behind the image.

## Where to get logos

Open-source projects usually publish official logo files, for example the CNCF artwork repository for Kubernetes and other CNCF projects. Logos are trademarks even when the software is open source, so check each project's trademark or brand guidelines before using them.

If an icon path is wrong or the file is missing, the component shows its 3D model without a badge and the browser console lists the missing file.
