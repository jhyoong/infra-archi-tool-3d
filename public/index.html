      Publishing changes

      Your edits are kept in this browser until you publish them. Choose Export to download infrastructure.json, replace public/data/infrastructure.json in the repository with it, and commit. GitLab Pages publishes the new map when the pipeline finishes.

      Logos and icons

      Put image files in the public/icons folder, then enter the path (for example icons/kubernetes.svg) in a component’s icon fields in edit mode.
